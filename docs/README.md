## ドキュメントの方針

- ユーザー向け文言・ドキュメントは **日本語** で統一。
- 「なぜそうしているか（意図・制約）」を残す。実装の丸写しは避ける。
- コードと乖離したら、コードを正としてドキュメントを更新する。
